# tool-2048

[![GitHub License](https://img.shields.io/github/license/hi2ma-bu4/tool-2048)](https://github.com/hi2ma-bu4/tool-2048/blob/main/LICENSE)
[![GitHub repo size](https://img.shields.io/github/repo-size/hi2ma-bu4/tool-2048)](https://github.com/hi2ma-bu4/tool-2048)

2048をプレイしながら、AIによる盤面解析や最善手の計算を行えるWebツールです。

通常の2048としてプレイするだけでなく、現在の盤面に対してAIがどの手を選ぶかを確認したり、AIに自動でプレイさせたりできます。

## Features

- 2048のプレイ
- キーボードによる操作
- 盤面の手動編集
- AIによる最善手の計算
- 各方向の手の評価
- AIによる自動プレイ
- 複数の評価アルゴリズム
- 探索深度の変更
- マージ回数の制限
- ランダムタイル自動追加のON/OFF
- Web WorkerによるAI計算
- WebAssemblyによる盤面評価
- リアルタイムなAI推奨手の表示

## Play

通常の2048と同じように、盤面を動かしてゲームを進めます。

### Keyboard

以下のキーで盤面を操作できます。

| 移動 | キー |
| --- | --- |
| 上 | `↑` / `W` |
| 下 | `↓` / `S` |
| 左 | `←` / `A` |
| 右 | `→` / `D` |

## Board Editing

盤面を直接編集して、任意の状態からAIの解析を行えます。

盤面の編集機能を使用することで、実際のゲームでは到達しにくい盤面や、特定の局面を再現してAIの挙動を確認できます。

## AI

AIは現在の盤面から複数の手をシミュレーションし、その中から最も良いと判断した手を選択します。

AIによる計算では、プレイヤーの操作だけでなく、操作後にランダムで追加されるタイルも考慮します。

### Expectimax

AIの探索にはExpectimaxを使用しています。

探索は以下の2種類のターンを交互に処理します。

1. プレイヤーが4方向のいずれかへ盤面を動かす
2. 空いているマスのいずれかにランダムタイルが追加される

ランダムタイルは通常の2048と同様に、

- `2`: 90%
- `4`: 10%

として扱います。

空きマスが複数ある場合は、それぞれのマスについて期待値を計算します。

## AI Algorithms

複数の評価方法を使用できます。

### Standard Heuristic

通常のヒューリスティック評価です。

以下の要素を組み合わせて盤面を評価します。

- Smoothness
- Monotonicity
- Empty Cells
- Max Tile

#### Smoothness

隣接するタイルの値がどれだけ滑らかに並んでいるかを評価します。

#### Monotonicity

盤面上のタイルが一定方向に向かって単調に並んでいるかを評価します。

#### Empty Cells

盤面に残っている空きマスを評価します。

2048では次の手を確保するために空きマスを維持することが重要になるため、AIの評価に使用しています。

#### Max Tile

盤面上の最大タイルを評価します。

### Pattern Evaluation

盤面全体のパターンを評価する方式です。

### Snake Pattern

大きなタイルを盤面の一方向へ集めるSnake型の盤面配置を評価します。

アルゴリズムによって盤面の評価方法が異なるため、同じ盤面でも推奨される手が変わる場合があります。

## Search Depth

AIの探索深度を変更できます。

探索深度を大きくすると、より先の手まで考慮して判断できるようになりますが、その分だけ計算量も増加します。

探索深度は `1` ～ `30` の範囲で設定できます。

## Merge Limit

AIのシミュレーションでは、マージされるタイルの上限を設定できます。

デフォルト値は `2048` です。

これにより、非常に大きなタイルが存在する盤面でも、計算量が過度に増加することを抑えられます。

## AI Recommendation

現在の盤面をAIに解析させると、各方向について評価を行い、その中から最も良い手を推奨します。

盤面の状態を変更すると、現在の盤面をもとに再度AIによる評価を行います。

これにより、プレイ中の局面でAIがどの方向を選択するのかをリアルタイムに確認できます。

## AI Auto Play

AIにゲームを自動でプレイさせることができます。

AIは現在の盤面を解析し、最も評価の高い手を選択してゲームを進めます。

自動プレイを使用することで、採用している評価アルゴリズムや探索深度によってプレイ結果がどのように変化するかを確認できます。

## Auto Add Tile

通常の2048では、プレイヤーが盤面を動かすたびに新しいタイルが追加されます。

この動作は設定によってON/OFFを切り替えられます。

OFFにすることで、ランダムタイルを追加せずに盤面を手動で操作したり、AIの評価だけを確認したりできます。

## Web Worker

AIの探索処理はWeb Worker上で実行します。

AIの計算は探索深度や盤面の状態によって負荷が高くなるため、メインスレッドとは分離して実行することで、UIの操作や描画への影響を抑えています。

AI Workerでは盤面を受け取り、指定されたアルゴリズムと探索設定を使用して最善手を計算します。

計算結果として、選択した手とそのスコアをメインスレッドへ返します。

## WebAssembly

盤面評価の一部にはWebAssemblyを使用しています。

AI WorkerからWebAssemblyの評価関数を呼び出すことで、探索中に大量に実行される盤面評価処理を高速化しています。

使用している評価関数には以下があります。

- `evaluate_board`
- `evaluate_pattern`
- `evaluate_snake_pattern`
